# Agent 与视频工作流验收

本轮从 `5208803` 开始，验收样例为 <https://www.bilibili.com/video/BV1V9PnzrExw/>。以下区分已验证的程序行为与仍需真实服务检验的效果，不把模拟模型测试描述为真实模型质量结论。

## 已验证

- 连续问答：基线在模拟供应商、真实 FastAPI / Agno / SSE / SQLite 下完成 12 轮，重建应用后再完成 3 轮；最后一轮通过历史工具读到第一轮信息。没有复现固定的「只能问五次」限制。
- 用户取消：供应商等待期间主动取消后，可以继续下一轮问答。
- 辅助摘要卡顿：已复现第 6 轮答案生成后，会话摘要无限等待导致整轮超时。自动摘要现在最多使用 10 秒，并在本轮总时限内为最终持久化预留 1 秒；时间不足时保留旧摘要，跳过这次辅助工作。
- 答案展示：SDK 确认正文结束后就发布最终文本，不再等待辅助摘要；任务完成仍以正常会话落盘为准，不提前关闭 SDK 流。
- 截止边界：主回答较慢、剩余时间不足时，辅助摘要让出时间；测试确认回答和完成事件被保存。
- 取消与异常：摘要保护不吞掉用户取消；正文结束事件没有内容字段时不会误判为供应商异常。
- 空回答：成功取得工具证据却没有最终文本时，只补发一次禁用工具的回答请求，带上原问题与本轮证据；仍为空则明确失败，不保存空白「已完成」。必需工具、审批结果和应用失败仍保留原有状态。
- 关闭与切换：会话异步回调受视图作用域约束，迟到响应不会串到另一个视频；关闭只停止观察，已经提交的后台任务继续。
- 轮询：转录等待会清理已用完的取消监听器，已取消或旧视频的响应不再更新当前状态；慢请求未结束时不积压新的任务与索引轮询。
- 画面工具：修复临时目录标识被真实资料库拒绝，以及文本主持模型错误承担视觉请求的问题。图像探测与描述均使用设置中的视觉角色，返回实际抽帧数量及非逐帧提示；失败时不记录「已看图」状态。
- 下载完整性：样例曾出现音频约 2170 秒而视频轨道仅约 835 秒、下载器仍报成功的文件。流时长检查现在拒绝该文件，完整重新下载通过；这是轻量元数据检查，不代替全片解码验证。
- 模型输出完整性：即使部分翻译恰好是有效 JSON，只要供应商标记为长度截断，也会作为可分段恢复的失败处理；内容过滤导致的不完整结果同样不交付。同步、异步及格式修复请求均覆盖。
- 字幕索引：工具输入与模型输出均拒绝布尔值作为片段编号，避免 `true` / `false` 被解释为第 1 / 0 个片段。
- 语言与范围：用户选择的字幕范围和「全部字幕」优先于模型工具参数；同视频不同模型、语言或运行参数的转写请求明确冲突，不再冒充为旧任务成功。命令后的换行、Tab 与全角空格均保留处理要求。
- 时间线开销：Canvas 从定义语义令牌的文档根节点读取样式，避免深层继承解析；此前三个 App 测试超时已消除，没有延长时限。

## 继续验收

- 单轮连续工具调用的预算、重复调用与恢复；保留有限上限，不能用无限循环掩盖错误。
- 翻译 / 转写对话框关闭、重新打开、切换视频、重复提交与显式取消。
- 样例视频下载、音频与画面检查、字幕处理和证据检索。
- 语言转换的目标语言、范围和结果完整性。
- 集成后的回归与性能检查。

## 验证边界

- 当前多轮及辅助摘要测试采用明显的假密钥和受控供应商响应，运行真实 SDK 和应用持久化流程；没有真实在线模型调用。
- 还没有验证用户账户可用性、真实 DeepSeek 回答质量、教程节点和雾效操作的识别效果。
- 第六轮摘要卡顿是本地可重现故障，不能据此断言它就是用户现场问题的唯一原因。
- 浏览器视觉交互尚未验收；前端生命周期结论来自组件测试。目前完整前端 78 个文件、420 项测试全部通过，未排除 App 测试。
