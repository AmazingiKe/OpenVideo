# ADR 0006：采用渐进披露的 Agent 交互与分阶段可观测性

- 状态：已接受
- 日期：2026-08-29

## 背景

长视频索引、跨片段检索和在线视觉验证可能持续较长时间。只显示加载动画无法判断是否仍在工作，展示全部推理与工具事件又会淹没最终答案。当前聊天组件自行实现滚动、消息气泡和标记，缺少 Markdown、正式附件、完整响应式状态和全量交互测试。

## 决策

### 全局侧边助手

助手使用全局常驻侧边面板，在播放器、摘要和转录页面共享入口。面板始终显示当前视频、文档或任务、时间范围以及当前视频或资料库检索范围。切换工作对象时根据会话绑定规则加载匹配会话，禁止沿用不匹配上下文。

聊天必须组合项目已有组件或 shadcn 的 `MessageScroller`、`Message`、`Bubble`、`Attachment` 和 `Marker` primitives。不得继续维护手写滚动吸底、气泡和附件卡片。模式选择使用 `ToggleGroup` 或符合现有设计系统的等价组件；所有颜色、状态、间距和动效使用全局语义 Token。

### 简洁回答与渐进披露

回答默认先给结论，使用简洁、明确的语言。只有复杂关系才使用列表、表格、差异块或时间线证据。Markdown 采用受控渲染，禁止任意 HTML。

工具调用、证据列表和详细阶段默认折叠。高、中置信度只显示精简已参考内容；低置信度主动展开相关或冲突证据。点击时间证据后播放器跳转并高亮对应范围，同时提供返回原播放位置的操作。

复杂或高影响任务开始前展示精简计划和阶段进度，普通查询直接运行。必须澄清时一次只问一个关键问题，给出推荐选择与影响，并允许自然语言回答。

### 渐进索引与任务中心

索引界面展示真实阶段、已处理范围与可用能力，不能用虚假进度掩盖未知时长。用户在索引期间可以提问；系统根据问题所需覆盖范围决定直接回答、给出低置信度暂定结果或等待更多索引。

应用内任务中心聚合并行 Agent 与后台索引。普通完成使用非打断通知；失败和等待批准提升提醒。离开当前页面后任务继续，回到会话可以恢复流式事件和滚动位置。

### 推理与耗时

每轮回答显示可点击的“思考若干秒”摘要。展开后展示结构化阶段，不展示或持久化模型原始思维链。每轮至少记录：

- 总耗时与首字时间。
- 模型路由与模型角色。
- 检索、视觉验证、模型等待、工具执行和生成耗时。
- 重试次数与最终状态。

文本使用可恢复的流式输出；阶段和增量事件需要合并后持久化，禁止因每个字符或固定高频轮询造成 SQLite 写放大。

### 本期与后续范围

本期实现上下文附件、范围提示、证据与置信度、索引状态、模式选择、分阶段耗时和聊天 primitives。用户满意度、撤销/重试等隐式反馈与自动修正策略只记录为后续决策，本期不采集。互联网检索也不进入本期。

## 验收

- 键盘、焦点、ARIA、对比度和 reduced motion 通过检查。
- 窄、中、宽布局以及浅色、深色主题均可用。
- 可复用组件具有 Storybook 的空、加载、流式、失败、低置信度和大量证据状态。
- 前端通过 lint、类型检查、单元测试、生产构建和 Storybook 构建。
- AI 输出测试验证用户内容、任务输入和附件确实进入模型上下文；证据时间点可以驱动播放器定位。

## 被否决的方案

- 展示原始思维链：内容可能不可靠、冗长并包含无关敏感信息。
- 只显示总耗时：无法定位长任务瓶颈。
- 展示全部底层事件：并行任务下噪声过大，并增加持久化压力。
- 纯文本回答：无法清晰表达证据、差异和复杂结构。

## 结果

- 长任务保持可理解、可恢复和不打断的体验。
- 用户可以快速核验答案证据，而不需要阅读工具日志。
- 性能问题能够定位到具体阶段和模型角色。
- UI 实现回到统一组件系统并具备可回归的视觉状态。

## 实现校准

截至 2026-08-29，全局助手已覆盖空、恢复加载、流式、失败、低置信度、大量证据、窄屏和深色主题的 Storybook 状态。运行事件持久化后唤醒 SSE 等待者，断线通过 `Last-Event-ID` 和数据库事件序号续传；空闲连接只发送低频保活，不再固定高频轮询 SQLite。
