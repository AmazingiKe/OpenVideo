# 播放器章节与语义提取

日期：2026-09-08

修订：2026-09-09，章节生成改为全文理解后统一规划。

## 问题

原有本地初始化依据停顿、镜头和时长生成片段，没有调用章节模型。语义模型给出的标题又在转换成时间轴片段时丢失；摘要在没有视觉描述时直接保存字幕全文。因此旧产物不能视为准确的章节总结。

初版语义提取仍先在各字幕窗口内分章，再仅凭边界附近几条字幕决定是否合并。这个流程缺少全文概述与整体结构判断，容易把定义、解释、示例拆成与字幕粒度接近的小节。

## 研究依据

- [VidChapters-7M（NeurIPS 2023）](https://arxiv.org/abs/2309.13952)：把视频章节化作为边界定位与标题生成的联合任务，使用语音与视觉证据。
- [Chapter-Llama（2025）](https://arxiv.org/abs/2504.00072)：以带时间的 ASR 和稀疏画面描述提供文本化证据，并用语音候选引导取帧。
- [Smart Chaptering / YTSeg（EACL 2024）](https://aclanthology.org/2024.eacl-long.25/)：针对口语转写进行主题分段及标题生成。

这里借鉴任务定义和证据组织流程，使用应用中配置的通用模型，不包含论文训练权重，不宣称复现论文指标。

## 决定

1. 章节只在播放器进度条呈现。复用 Vidstack 原生章节轨道，按时长显示分段、播放与缓冲进度；悬停显示标题、摘要，PageUp / PageDown 跳章。编辑时间线只保留标记、转写、候选与事件分析。
2. 用户点击“生成章节 / 重新生成章节”后，复用已有转写，先独立生成全文概述与带原文索引的内容推进记录。目录规划仅接收全文概述和不带索引的内容脉络，输出整体结构说明、章节主题、整章内容概述和独立成章的依据；随后单独定位原文范围，强制保持目录的数量与顺序。同一讲解目标下的定义、解释、示例通常归入一章；只有一个主要议题时允许只生成一章。
3. 长输入分块只生成内容理解记录，保留来源索引和结尾内容，再逐级压缩并贯通全文，不在窗口内生成章节，不把记录条数当成章节数。各层均校验完整覆盖，压缩未缩短时中止，避免循环请求。可用时在初步主题起点提取稀疏关键帧，加入带时间的 OCR 和画面观察，再从全文重新判断。
4. 强制检查整数字幕索引、完整覆盖、连续性、重叠和越界。结构或索引无效时，携带原始材料和具体校验错误让模型修正一次；仍无效则失败，禁止通过补边界掩盖内容遗漏。最终导航区间从零开始，章末等于下一章起点，最后一章覆盖视频结尾。
5. 保留全文规划的标题和内容范围，传递到章内摘要阶段。摘要客观介绍整章讲了什么及内容之间的联系，避免逐条改写字幕或罗列知识点；只以最终章内的转写与视觉证据为事实依据，长章分块压缩，随后复查术语、数字与概念关系。
6. 整批章节和摘要生成成功后才保存。模型失败或生成期间原文、章节被修改时，保留已有结果并显示原因。

## 验证与边界

单元测试覆盖先理解再规划再定位、目录规划不接收字幕索引、定位不能增减章节、跨窗口统一规划、多级压缩保留全文范围、单一主题保留一章、非法或不完整模型输出、压缩不收敛、标题与内容范围传递、连续区间、长章结尾证据、摘要复核、后台任务和失败保留。已有前端测试覆盖切换视频取消轮询、按时长分段、悬停、键盘跳章及播放器与编辑时间线的拖动同步。

初版曾使用资料库中的两段真实转写做文本路径抽查，数据结构视频得到 5 个主题章节，音画同步视频得到 6 个主题章节。抽查发现初稿把同义解释误当成两个概念；加入原文复核后，该样例改为“数学逻辑模型关注抽象视图”。这些历史结果不代表本次全文规划流程的效果，也没有人工标注集上的边界或摘要准确率评估。

本次使用配置中的模型做真实文本路径抽查：38 条转写的数据结构入门课程生成 3 章，按“重要性与实例、定义与两个研究角度、后续学习内容”组织；1340 条转写的着色器教程跨越 3 个输入窗口，全文规划生成 4 章，按“基础概念、描边实现、HDR 发光与修复、总结与扩展”组织，具体参数设置和编写步骤归入描边实现。数据结构课程的一章另经过章内原文摘要复核。抽查没有覆写资料库，也没有覆盖视觉补充路径；章节粒度和长输入压缩后的边界仍受模型判断影响。

已有章节不会自动覆写，需要主动重新生成。导入时的本地证据初始化仍可离线运行；语义重建要求已有转写和在线模型。没有语音的纯视觉章节提取及专用模型训练不在这次实现范围内。字幕质量、稀疏取帧覆盖和模型能力仍会影响结果，复核步骤也不能保证消除所有事实错误。
