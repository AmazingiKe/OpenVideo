# 播放器章节与语义提取

日期：2026-09-08

## 问题

原有本地初始化依据停顿、镜头和时长生成片段，没有调用章节模型。语义模型给出的标题又在转换成时间轴片段时丢失；摘要在没有视觉描述时直接保存字幕全文。因此旧产物不能视为准确的章节总结。

## 研究依据

- [VidChapters-7M（NeurIPS 2023）](https://arxiv.org/abs/2309.13952)：把视频章节化作为边界定位与标题生成的联合任务，使用语音与视觉证据。
- [Chapter-Llama（2025）](https://arxiv.org/abs/2504.00072)：以带时间的 ASR 和稀疏画面描述提供文本化证据，并用语音候选引导取帧。
- [Smart Chaptering / YTSeg（EACL 2024）](https://aclanthology.org/2024.eacl-long.25/)：针对口语转写进行主题分段及标题生成。

这里借鉴任务定义和证据组织流程，使用应用中配置的通用模型，不包含论文训练权重，不宣称复现论文指标。

## 决定

1. 章节只在播放器进度条呈现。复用 Vidstack 原生章节轨道，按时长显示分段、播放与缓冲进度；悬停显示标题、摘要，PageUp / PageDown 跳章。编辑时间线只保留标记、转写、候选与事件分析。
2. 用户点击“生成章节 / 重新生成章节”后，复用已有字幕，联合预测主要主题边界与中文标题。输入窗口仅限制上下文长度，不作为固定时长章节。
3. 可用时在候选主题起点提取稀疏关键帧，加入带时间的 OCR 和画面观察，重新判断主题边界。长输入使用重叠窗口，并核对候选边界两侧的原文以合并同一主题。
4. 强制检查整数字幕索引、完整覆盖、连续性、重叠和越界。最终导航区间从零开始，章末等于下一章起点，最后一章覆盖视频结尾。
5. 保留模型标题；摘要只使用最终章内的字幕与视觉证据，长章分块压缩，随后对照证据复查术语、数字与概念关系。禁止用字幕全文伪装摘要。
6. 整批章节和摘要生成成功后才保存。模型失败或生成期间原文、章节被修改时，保留已有结果并显示原因。

## 验证与边界

单元测试覆盖非法模型输出、标题传递、连续区间、长章结尾证据、摘要复核、后台任务、失败保留以及切换视频取消轮询。浏览器测试覆盖按时长分段、悬停、键盘跳章及播放器与编辑时间线的拖动同步。

使用资料库中的两段真实转写做文本路径抽查，数据结构视频得到 5 个主题章节，音画同步视频得到 6 个主题章节。抽查发现初稿把同义解释误当成两个概念；加入原文复核后，该样例改为“数学逻辑模型关注抽象视图”。这只是样例检查，没有人工标注集上的边界或摘要准确率评估。

已有章节不会自动覆写，需要主动重新生成。导入时的本地证据初始化仍可离线运行；语义重建要求已有转写和在线模型。没有语音的纯视觉章节提取及专用模型训练不在这次实现范围内。字幕质量、稀疏取帧覆盖和模型能力仍会影响结果，复核步骤也不能保证消除所有事实错误。
