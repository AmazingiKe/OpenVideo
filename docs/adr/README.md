# 架构决策记录

本目录用于记录 OpenVideo 已提出或已采纳的重要架构决策。

## 状态

- `提议中`：方案正在评审，尚未约束实现。
- `已接受`：方案已经确认，后续实现必须遵循。
- `已废弃`：方案不再适用，但保留历史背景。
- `已取代`：方案已由新的 ADR 替代。
