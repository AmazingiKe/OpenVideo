# ADR 0011：标记内容与可选重要程度

- 状态：已采纳
- 日期：2026-09-07

标记在时间点或时间段上记录用户注释 `content` 和可选重要程度 `importance`。注释保存时去除首尾空白；评分 0 表示未设置，1～5 表示显式星级。

时间位置始终加入 AI 上下文。仅有注释时提供注释，且不附加评分；仅有评分时提供评分；两者都有时一并提供；两者都没有时按 1 星兜底。兜底仅用于上下文和权重计算，不改写持久化评分。注释是用户对内容的说明，不能当作已验证的视频证据或执行指令。

标记与总结 Agent、时间线分析、局部事件分析及配图规划使用同一规则。仅有注释的标记保留在分析上下文中，不增加数字评分权重。局部事件分析保存当时的注释与评分快照；修改标记使关联旧分析过期。

现有编辑浮层统一编辑内容、评分、时间和形态，右键菜单及 Enter 均可进入。AI 调整边界保留原注释；合并标记按时间顺序合并非空注释并去重，沿用最高显式评分。

旧标记缺少 `content` 时读取为空。SQLite 通过增量补列保存内容和事件分析注释快照，不为增加字段重建资料库。JSON 业务文件继续作为可重建投影的来源。
