# 界面风格

Web 统一使用 Final Cut Pro 风格的深色工作区，不再提供浅色主题或跟随系统切换。配色参考[苹果官网界面截图](https://www.apple.com.cn/final-cut-pro/)，顶栏参考确认过的标题截图；属于视觉近似，并非苹果官方设计 Token。

## 配色与层级

| 用途 | 当前配色 |
| --- | --- |
| 主工作区、时间线画布 | `#1f1f1f` |
| 卡片、轨道标题 | `#2b2b2b` |
| 浮层、时间线工具栏 | `#333333` |
| 主文字 / 辅助文字 | `#eeeeee` / `#b5b5b5` |
| 主要操作、输入焦点 | `#79b5f7` |
| 菜单高亮背景 | `#285b92` |
| 时间线片段选中描边 | `#ffda38` |

以中性灰区分层级，弱化分隔线。黄色用于编辑选择和证据强调，不作为全站主色；播放头使用白色。转写、全片分析、事件分析和标记分别保留紫、蓝、青、琥珀色。

## 顶栏

- 左上角仅显示 **Open Video**，不放图标；字号 **20px**、字重 **600**、行高 **24px**。
- 桌面顶栏最小高度 **48px**，内容垂直居中；窄屏导航换到第二行，允许顶栏增高。
- 背景纵向渐变：顶部 `#282828` → 中间 50% 处 `#171717` → 80% 至底部 `#131313`。
- 渐变只用于顶栏，内容面板保持纯色，避免干扰媒体画面。

## 实现约定

颜色及尺寸以 [styles.css](../../apps/web/src/styles.css) 中的语义 Token 为准，组件和 Canvas 不写临时色值或局部颜色变量。顶栏使用 `--topbar-*` Token，复用 [Topbar](../../apps/web/src/app/Topbar.tsx)。

沿用现有 shadcn/Radix 组件和语义状态，保留清晰的键盘焦点、禁用及错误反馈。视觉变更检查桌面与 375px 窄屏，并运行相关 Storybook 交互及无障碍测试。历史文档中的明暗双主题要求，以本页的单一深色主题约定为准。
